# Результаты полного запуска

Время ниже указано в секундах, это среднее значение по 5 повторам.

Случайный порядок ключей, `n = 1000000`:

| Дерево | Вставка | Удаление |
| --- | ---: | ---: |
| `B-Tree` | 0.421 | 0.168 |
| `Red-Black` | 1.192 | 0.669 |
| `AVL` | 1.364 | 15.331 |
| `Splay` | 1.799 | 1.377 |
| `Skip-list` | 2.661 | 1.562 |
| `Treap` | 24.597 | 0.849 |

`Naive BST` проверялся на меньшем размере: на случайном входе `n = 100000` вставка заняла 0.035 с, удаление - 0.018 с. На отсортированном входе для него использовался только `n = 10000`, поэтому с деревьями на `n = 1000000` его напрямую сравнивать нельзя.

По итогам полного запуска лучшее качество работы показал `B-Tree`: он быстрее остальных и на вставке, и на удалении. `Red-Black` выглядит самым сильным универсальным вариантом среди обычных бинарных деревьев. `AVL` хорошо вставляет, но в этих замерах заметно проигрывает на удалении.
